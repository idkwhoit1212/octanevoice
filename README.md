# Octane 3D Positional Voice Server

Полноценный 3D позиционный голосовой чат для Roblox Octane (2021) на базе WebRTC и Web Audio API.

## Возможности:
- **3D звук (HRTF Panning)**: звук в наушниках зависит от расстояния и угла между персонажами в игре.
- **Вход по 4-значному коду**: игрок вводит команду `/voice` в игре, получает 4-значный код и вводит его на сайте. Никаких паролей и скачиваний.
- **Поддержка телефонов и ПК**: веб-клиент открывается в браузере или на смартфоне рядом.
- **Анимация бабла над головой**: классический диалоговый фон с динамическими иконками громкости спикера в Roblox.
- **HUD индикатор микрофона**: статус микрофона и громкость прямо на экране в игре.

## Как запустить на бесплатном хостинге (Render.com / Railway):
1. Загрузите эту папку в свой GitHub репозиторий.
2. Зайдите на [render.com](https://render.com) -> New -> Web Service.
3. Выберите ваш репозиторий.
4. Укажите:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. Нажмите Deploy. Получите адрес вида: `https://your-app.onrender.com`.
6. Вставьте этот URL в модуль Roblox `ServerScriptService.raidRoleplay.Modules.PositionalVoice`.

## Локальный запуск для теста:
```bash
npm install
npm start
```
Сервер запустится на `http://localhost:3000`.
